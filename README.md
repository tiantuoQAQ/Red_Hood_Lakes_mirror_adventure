# 镜 / MIRROR — 弹幕闪避原型

CODEJAM 2026 参赛作品原型。玩法参考《东方冰之勇者记》（东方同人，GAMEPULSE 开发，Unity），
机制层面做复刻与再设计，美术与关卡完全原创。

---

## 怎么运行

零依赖、零构建、零素材（全部图形由代码绘制）。

**直接双击 `index.html`** 即可用浏览器打开。

如果浏览器对本地文件限制过严，用任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/
```

> README 交付要求里写明：需要 **Chrome / Edge 最新版**，无需安装任何引擎运行时。

## 核心机制（复刻来源）

- **生命次数制**：挨三下直接重来，不做血条，难度曲线靠判定宽松度而不是数值平衡。
- **冲刺无敌帧**：16 帧无敌 / 12 帧位移，冷却 28 帧。
- **球形态**：全屏飞行、**持续无敌**、不能攻击、持续消耗体力；
  **落地自动取消**——退出条件不需要额外按键，这是原作最关键的手感设计。
- **擦弹**：贴身擦过弹幕给勇气值，奖励「贴着躲」而不是「躲得远」。
- **BOSS 三阶段**：血量阈值切换，切换时清屏并给一段空档。
- **弹幕镜像**：BOSS 有一个以镜面轴为中心的镜像分身，扇形与螺旋弹幕都是成对发射的。

## 反馈层次（手感的主要来源）

引擎不决定手感，反馈层次和迭代速度决定。当前实现的反馈：

| 事件 | 视觉 | 音效 |
| --- | --- | --- |
| 命中 BOSS | 橙色伤害数字 + 火花 + 微震 + 全屏轻闪 | 噪声 + 三角波 |
| 擦弹 | 橙色 `+1` 飘字 + 小火花 | 高频双音 |
| 冲刺 | 残影 + 火花 | 滤波噪声 |
| 球形态进出 | 粒子爆发 + 体力条出现 | 上下滑音 |
| 受伤 | 全屏品红渐晕 + 强震 + 顿帧 4 帧 | 噪声 + 低频锯齿 |
| 换阶段 | 清屏闪白 + 大字横幅 | 双音叠加 |
| 冰封 | 粒子爆发 + 伤害数字 | 上滑正弦 |
| 死亡 / 通关 | 覆盖层 | 下滑锯齿 / 上行琶音 |

音效全部由 WebAudio **程序化合成**，没有音频文件，因此不存在素材授权问题。
屏幕震动使用衰减正弦而非随机抖动，避免画面糊掉。

## 与比赛规则的关系

**三色相限制**：全画面只使用 3 个色相加灰阶，因为所有图形由代码生成，不存在贴图带入的杂色。

| 用途 | 颜色 | 色相 |
| --- | --- | --- |
| 玩家 / BOSS 轮廓 / 冰 | `#5fd8ff` | 青 ≈ 195° |
| 弹幕 / 危险 | `#ff3fa4` | 品红 ≈ 330° |
| 射击 / 勇气 / 擦弹 | `#ffa53f` | 暖橙 ≈ 33° |
| 背景 / 文字 / 判定点 | 灰阶 | 无 |

**题目「镜」**：镜面轴是可见的舞台元素，弹幕成对镜像发射，BOSS 的镜像分身始终以幽灵形态提示，
是玩法机制而非装饰。

## 手感调参

按 `F2` 打开面板，所有参数**运行时实时生效**，不需要改代码：

移动速度、跳跃初速、判定点半径、冲刺无敌帧/持续帧、球形态速度与体力消耗、
受伤无敌帧、弹速倍率、BOSS 血量。右下角「导出 JSON」可复制当前参数。

调参之后把数值提交到仓库，别只留在自己的浏览器里。

## 目录结构

```

src/game.js         游戏状态、玩家、BOSS、碰撞
src/render.js       渲染与 HUD、覆盖层
src/main.js         固定步长循环、调参面板绑定
test/logic_test.js  逻辑回归测试
_verify.html        截图校验页（不加载主循环）
```

## 已知限制

- 目前只有 1 个 BOSS、4 种弹幕招式，没有音效和 BGM。
- 镜像轴的「反射」玩法（把弹幕打回去）尚未实现，是下一步的候选方向。
- 没有存档、没有菜单，`R` 直接重开。
