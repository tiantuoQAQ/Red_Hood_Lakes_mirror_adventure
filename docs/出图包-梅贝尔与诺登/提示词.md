
## 三、梅贝尔 · 三个表情差分

在上面那张出好之后，**用那张当参考图**，只改表情，其余全部锁定（画风、姿势、构图、黑底、配色都不变）：

**① 闭眼**
```
保持参考图的一切不变（角色、画风、头身比、服装、构图、纯黑背景、配色），只把眼睛闭上。
眼睛自然闭合、眉毛放松、嘴角带一点笑意，像在自顾自哼小曲。
不要改姿势、不要改裙子、不要改构图。
```

**② 睁眼 · 小恶魔打量**
```
保持参考图的一切不变，只改表情为：眼睛睁开看向镜头，嘴角单边微微上扬，
带一点狡黠的好奇（不要邪恶、不要张牙舞爪）。
```

**③ 回眸**
```
保持参考图的一切不变，改成回眸：身体朝前站着，头向侧后方转过来看着镜头，
长发随转身微微甩开，表情是发现有趣东西的坏笑、眼睛睁开。
```
