# 任务：把网页版《镜》移植成 Godot 4 项目（手感必须一致）

## 0. 最重要的一句话

**网页版是唯一基准（ground truth）。** 它不是“参考”，是标准答案：
手感、数值、节奏、表现，全部以网页版为准。你写的 Godot 版如果和网页版手感不一致，**改 Godot，不要改网页版**。

## 1. 开工前必须做的三件事

1. 在项目根目录运行：
   ```
   python -m http.server 8000
   ```
   浏览器打开 `http://127.0.0.1:8000/index.html`，**亲自玩 5 分钟**：跳、冲刺、进球形态、射击、躲弹幕、放技能。
2. 打开 `art_preview/visual_reference.png`，这是 8 个界面的对照截图（标题 / 走位 / 王座 / 对话 / 战斗+我方弹幕 / 球形态 / 必杀演出 / BOSS 面板）。
3. 读 `docs/Godot移植规格.md`（手感参数全表、球形态、鼠标瞄准、弹幕、资源路径、验收清单）。
   然后再读源码：`src/config.js`（所有数值）、`src/game.js`（玩家/BOSS/碰撞）、`src/patterns.js`（弹幕）、`src/render.js`（绘制）。

**不要凭想象补机制。** 任何你没在网页版里见到的机制，都不要加。

## 2. 游戏是什么

横版 2D、弹幕躲避 + 射击（Bullet-hell × 平台动作）。
玩家操纵小红帽**蕾克**，在“镜中世界”里依次打两个 BOSS：
- 猩红魔姬·雷帝（240 血，5 阶段）
- 扭曲的黑童话作家 玛丽苏（420 血，6 阶段，**总阶段数对玩家隐藏**）

逻辑分辨率 **1280×720**，地面线 **y=574**，世界宽 **2400**（有横向镜头）。
**固定 1/60 秒步长**，用 `_physics_process`，`physics_ticks_per_second = 60`。

## 3. 输入（含鼠标，务必照抄）

| 动作 | 键 |
| --- | --- |
| 左/右 | `A` `D`，也接受 `←` `→` |
| 上/下 | `W` `S`，也接受 `↑` `↓` |
| 跳跃 | `Space` |
| **冲刺** | `Shift`（左右）/ `K` / **鼠标右键** |
| **射击** | `J` / `Z` / **鼠标左键** |
| 技能 | `L` / `X` |
| 开始 / 暂停 / 重开 / 静音 / 跳过 | `Enter` / `P` / `R` / `M` / `Tab` |

- **射击方向 = 鼠标世界坐标方向**（`get_global_mouse_position()`），**没有自动瞄准**。
- 鼠标**从未移动**过时，退化为面朝方向射击。
- 鼠标右键冲刺要 `eat right-click`（不要弹右键菜单）；窗口失焦清空所有按键。
- 玩家**不能**用鼠标移动，只能用键盘移动。

## 4. 核心机制（每条都必须实现）

### 4.1 球形态（无敌球）——这套战斗的灵魂

**进入条件（三条同时满足）**：
1. 在空中（不在地面）
2. **按住 `W`（上）**
3. **按下冲刺键**（鼠标右键 / Shift / K，是“本帧按下”）
4. 体力 `stamina > 20`

**进入瞬间**：`vx *= 0.4`、`vy = -450`（向上弹），接下来 **5 帧强制上冲**（忽略垂直输入）。
**期间**：全程**无敌**、方向键直接给速度（合速度恒为 450）、体力 `-32/s`。
**落地**：不退出，贴着地面悬浮。
**退出**：**松开冲刺键立刻变回人**，或体力耗尽。
**体力**：人形态在地面 `+26/s`，上限 100。
**地面上按 W+Shift**：只触发普通冲刺，**不进球形态**（否则变成站桩无敌）。

### 4.2 冲刺

速度 1020、持续 12 帧、无敌 16 帧、冷却 16 帧（结束后才起算）。
**起步 3 帧从 45% 推到 100%**（不要瞬间满速）。结束后**滑行 6 帧**再收（速度按 0.72 保留率收敛）。
带 **8 帧输入缓冲**：冷却中提前按下，冷却结束瞬间自动触发。

### 4.3 移动与跳跃

地面最大速度 340、加速度 4600、摩擦 3800；跳跃初速 -700、重力 2000。
跳跃带 **8 帧缓冲**。**不要做二段跳/郊狼时间**（网页版没有）。

### 4.4 射击

间隔 9 帧、速度 900、伤害 3、半径 5。
子弹带**弱磁吸**：距 BOSS 280px 内才会轻微转向（每秒最多 3.4 弧度，越近越强），**不是追踪弹**。

### 4.5 擦弹（graze）

判定半径 4（**很小**），擦弹环再外扩到 30。
每次擦弹：勇气 `+1×倍率`、连击 +1（80 帧窗口，超时归零）、**冲刺冷却 -2 帧**。
倍率 = `1 + floor(连击/5)*0.5`，上限 3 倍。

### 4.6 技能

勇气满 100 释放：
- 前期「冰封」：36 伤害、130 帧无敌
- 解锁「红之惨剧」后同一个键升格：**清空全屏弹幕** + 80 伤害 + 200 帧无敌 + 顿帧震屏

### 4.7 受击

3 条命。受击掉 1 条 + 70 帧无敌 + 勇气 -18 + 连击清零。
**绝对不要加击飞、不要加顿帧**——正在躲的那口气不能被打断。

### 4.8 BOSS 血条（照抄，别自己发挥）

**整场只有一根血条**，显示当前阶段血量。打空 → 直接进入下一阶段 → **血条回满**。
- 猩红魔姬：回满 **4** 次（共 5 段）
- 玛丽苏：回满 **5** 次（共 6 段，界面显示 `STAGE n / ?`，不告诉玩家总数）

### 4.9 弹幕招式（10 种）

`ring` 环形、`mirrorFan` 双向扇形（镜像，贴主题）、`spiral` 螺旋、`rain` 落雨、
`lances` 预警线→高速穿刺、`orbit` 环绕、`crossfire` 左右对射、`laser` 蓄力激光（宽 26）、
`bossDash` BOSS 冲刺（1500 速度）+ 到位环形、`homing` 追踪（速度 215、每秒转 1.7 弧度）。

每招有时长（220~300 帧），阶段内按顺序循环。

### 4.10 镜头

跟随玩家，平滑 `lerp`（`1 - pow(0.0001, dt)`），钳制 `0..WORLD_W-1280`。
BOSS 出场时双目标取景（玩家+BOSS 都进画面，两侧各留 160px）。走位段默认锁镜头。

### 4.11 手感反馈（**不做这些一定“生硬”**）

| 反馈 | 做法 |

| 命中顿帧 | 打中 BOSS / 放技能时冻结 4~10 帧（只更新粒子） |

| 冲刺残影 | 每 2 帧记一个点，12 帧淡出 |
| 球形态拖尾 | 每 2 帧撒粒子，方向与速度相反 |

## 6. 交付顺序（每个里程碑做完再进下一个）

- **M1 移动手感**：左右跑、跳、冲刺（含 3 帧起步 + 6 帧滑行 + 缓冲）。验收：跑跳冲刺不粘不滑。
- **M2 球形态**：三条进入条件 + 强制上冲 + 无敌 + 松开退出 + 体力条。验收：贴地悬浮、不自动退出。
- **M3 射击与鼠标**：鼠标瞄准、9 帧间隔、弱磁吸。验收：绕圈动鼠标，弹道跟着转。
- **M4 BOSS 与血条**：单条血条、打空回满、阶段技名、10 种弹幕。验收：打满 5/6 段能进下一章。
- **M5 擦弹/勇气/技能**：擦弹连击、勇气条、冰封与红之惨剧。
- **M6 表现层**：顿帧、震屏、残影、拖尾、红晕、BOSS 面板、必杀演出、镜之碎片。
- **M7 剧情**：11 章对话（`src/story.js` 的数据结构可以直接搬）、登场竖幅、走位段。

## 7. 明确禁止（做了就是“生硬”）

1. ❌ 用 `move_and_slide` 处理位移 → ✅ 手写速度积分
2. ❌ 冲刺瞬间满速 → ✅ 3 帧从 45% 推到 100%
3. ❌ 玩家受击顿帧/击飞 → ✅ 只有命中与技能才顿帧
4. ❌ 子弹自动瞄准 → ✅ 只朝鼠标，弱磁吸仅在 280px 内
5. ❌ 落地退出球形态 → ✅ 只有松开冲刺才退出
6. ❌ 球形态按一下切换 → ✅ 按住维持
7. ❌ 血条做成 N 根并列 → ✅ 一根条，打空回满
8. ❌ 震屏用随机抖动 → ✅ 衰减正弦
9. ❌ 用 `_process` 做物理 → ✅ `_physics_process` + 60Hz

- 想验证手感：网页版按 `F2` 可以实时拖滑块改参数，你的 Godot 版也应该做同等调试面板
