| 项 | 值 |

## 2. 输入映射（必须一致）

| 动作 | 键 |
| --- | --- |
| 左 / 右 | `A` / `D`，也接受 `←` / `→` |

## 3. 鼠标瞄准（这一条最容易做错）

- **射击方向 = 鼠标方向，没有自动瞄准**。
- 鼠标坐标要换算成**世界坐标**：`world_x = mouse_canvas_x + camera_x`。
- 鼠标的“上一帧位置”如果没变化过（从未移动），则退化为**朝向**射击（面朝右 → 角度 0，面朝左 → π）。
- 子弹不会追踪敌人，只带**弱磁吸**（见 §6）。

Godot：`get_global_mouse_position()` 直接是世界坐标，别再用 `get_viewport().get_mouse_position()` 手算。

## 4. 玩家移动模型（空中 / 地面同一套手写积分）

**不要用 `move_and_slide` + 重力**做这套，参数会失真。按下面的伪代码手写速度：

| 参数 | 值 | 单位 |
| --- | --- | --- |
| 地面最大速度 `speed` | 340 | px/s |
| 加速度 `accel` | 4600 | px/s² |
| 摩擦 `friction` | 3800 | px/s² |
| 跳跃初速 `jumpVel` | -700 | px/s（向上为负） |
| 重力 `gravity` | 2000 | px/s² |
| 视觉半径 `visualR` | 20 | px（碰撞/边界用这个） |
| 判定半径 `hitR` | **4** | px（**必须远小于视觉半径**，这是躲弹幕的手感根源） |

```
每帧（1/60）：
  if 在地面:
     目标速度 = dir * speed
     if dir != 0: vx += dir * accel * dt; vx = clamp(vx, -speed, speed)
     else:        vx 向 0 按 friction*dt 收敛（越过 0 就置 0）
  else:
     vy += gravity * dt
     vx 同样按 accel/friction 处理（空中也保留水平控制，减速更弱）
  x += vx * dt; y += vy * dt

  边界钳制：left/right 撞到就 vx = 0；顶部撞到且 vy<0 则 vy = 0
  落地：y + visualR >= GROUND_Y → y = GROUND_Y - visualR, vy = 0, onGround = true
```

**跳跃**：`Space` → `vy = -700`，并置 `onGround = false`。
**跳跃缓冲**：按跳跃键后 8 帧内落地会自动跳（`jumpBuf = 8`）。
**郊狼时间**：网页版预留了字段但**没启用**（始终 0），Godot 里也不要做，做了会变“空中二段跳”。

## 5. 球形态（**最容易漏，也是这套战斗的核心**）

### 进入条件（三条同时满足）

1. **不在平台上**（`!onGround`，必须离地）
2. **按住 ↑（W）**
3. **按下冲刺键**（该帧的“按下”，不是按住）
4. 体力 `stamina > 20`

满足后：吃掉这次冲刺按下（**不再额外触发一次普通冲刺**），进入球形态。

### 进入瞬间

| 动作 | 值 |
| --- | --- |
| 水平速度 | `vx *= 0.4`（先刹车） |
| 垂直速度 | `vy = -450`（向上弹，`ballSpeed = 450`） |
| 起手强制上冲 | `ballLaunch = 5` 帧：这 5 帧内**忽略垂直输入**，一定往上冲 |
| 无敌 | 球形态全程**无敌**（不吃弹） |

### 期间

- 体力 `-32/s`（`ballDrain`），体力归零 → 自动退出
- 移动：方向键直接给速度，**大小恒为 450**，八向归一化；`facing` 跟着水平方向
- 落地：**不退出**，`vy = 0` 贴地悬浮，等玩家松手（`ballExitOnLand = false`）

### 退出

- **松开冲刺键 → 立刻变回人**（`vx = vy = 0`）——这是玩家期待的控制感
- 体力耗尽 → 退出
- 不是落地退出，不是时间到退出

### 体力回复

- 人形态在地面：`+26/s`
- 上限 100

### 为什么这么设计（别改）

球形态 = 无敌 + 高速 + 贴地滑行，是玩家躲高密度弹幕的“呼吸阀”。
代价是：进入要“离地 + 上 + 冲刺”三键、体力有限、且**松手就掉出无敌**。
如果改成“按一下切换”或者“落地自动退出”，整个难度曲线会崩。

## 6. 冲刺 / 射击 / 擦弹 / 技能

### 冲刺

| 参数 | 值 |
| --- | --- |
| 速度 | 1020 px/s |
| 持续 | 12 帧 |
| 无敌帧 | 16 帧 |
| 冷却 | 16 帧（在冲刺结束后才开始算，即 `cd = 16 + 12`） |
| 起步加速 | **3 帧从 45% 推到 100%**（不要瞬间满速，会“啪”一下） |
| 结束滑行 | 6 帧，速度向目标值按 0.72 保留率指数收敛 |
| 输入缓冲 | 8 帧（冷却结束前一瞬间按下也认） |
| 残影 | 每 2 帧留一个轨迹点，12 帧淡出 |

### 射击

| 参数 | 值 |
| --- | --- |
| 间隔 | 9 帧 |
| 速度 | 900 px/s |
| 伤害 | 3 |
| 半径 | 5 |
| 弱磁吸 | 距 BOSS 280px 内，每秒最多转 3.4 弧度 × (0.35 + 强度)，越近越强 |

**没有弹道贴图**：我方的子弹是**程序绘制的四角星 + 十字光刺 + 拖尾**（`render.js` 的 `drawBulletStar`）。
Godot 里两种做法都行：
- 简单：画一个白/红色小星形 `Polygon2D` 贴图（自己画 32×32 PNG）
- 或直接 `_draw()` 画星形路径（和网页版一致，推荐）

### 擦弹（graze）

| 参数 | 值 |
| --- | --- |
| 擦弹半径 | 30 px（**判定半径 4 + 擦弹环 26**） |
| 连击窗口 | 80 帧（超过就断） |
| 每 N 次升档 | 5 次 |
| 勇气倍率 | `1 + floor(链/5) * 0.5`，上限 **3 倍** |
| 每次勇气 | `1 × 倍率` |
| 冲刺冷却返还 | 每次擦弹 **-2 帧** |

擦弹时：白色小粒子 + 勇气数字飘字 + 音效音高随连击升高。

### 技能（勇气满 100 可放）

| 版本 | 效果 |
| --- | --- |
| 未解锁（前期） | 「冰封」：36 伤害、130 帧无敌、震屏 12、顿帧 6 |
| 解锁「红之惨剧」后（同键升格） | **清空全屏弹幕** + 200 帧无敌 + 80 伤害 + 顿帧 10 + 震屏 18 + 横幅 |

## 7. 受击规则（**别加击飞**）

- 生命 3 条，受击掉 1 条
- **不击飞、不顿帧**：位移和速度保持连续（正在躲的那口气不能断）
- 受击后 70 帧无敌 + 12 帧白闪
- 勇气 -18，擦弹链清零
- 表现：震屏 9、屏幕四周红晕 18 帧、粒子 18 颗、音效

## 9. 镜头

- 世界比屏幕宽（2400 vs 1280），镜头跟随玩家
- 平滑：`cam += (target - cam) * (1 - pow(0.0001, dt))`
- 钳制：`0 .. WORLD_W - 1280`
- BOSS 出场时「双目标取景」：把玩家和 BOSS 都框进画面，两侧各留 160px 余量
- 走位段：默认锁镜头；只有显式开启（王座段/结局段）才跟随

## 10. 手感反馈（缺了就会“生硬”）

| 反馈 | 参数 |
| --- | --- |
| 命中顿帧 | 打中 BOSS 或放技能时 `hitstop` 4~10 帧（期间画面冻结、只更新粒子） |

## 11. 美术资源清单（哪里有什么）

### 11.1 玩家（蕾克）—— 四层分件

```
art/rek/cape.png   ← 斗篷（最底层）
art/rek/hair.png   ← 头发（次底）
art/rek/body.png   ← 身体（中间）
art/rek/head.png   ← 头（最上，绕脖子旋转）
```

- **四张图必须同尺寸、同站位**，画面里角色脚底中线对齐
- `CFG.sprite.scale = 0.5`（按 2 倍出图，用时缩一半）
- 缺任意一层会自动跳过该层；`body` 缺失时整体退回程序化图形（当前就是占位状态）
- 对齐微调参数：`hairDx/hairDy`、`capeDx/capeDy`、`headDx/headDy`

## 12. 验收清单（按顺序打勾，任何一条不过就是手感没对上）

1. **球形态**：跳起来 → 按住 W → 按 Shift → 变成无敌光球向上弹；**松开 Shift 立刻变回人**；
   贴地时不会自动退出；体力耗尽自动退出；地面上按 W+Shift 只触发普通冲刺。
2. **冲刺**：起步 3 帧内速度从 45% 推到 100%，结束后有 6 帧滑行而不是硬停；冷却期间提前按下也能在冷却结束瞬间触发。
3. **射击**：子弹朝**鼠标**飞，绕圈移动鼠标子弹跟着转；鼠标不动时朝朝向飞；子弹靠近 BOSS 会轻微拐弯。
4. **擦弹**：贴身躲弹时勇气涨、连击数字跳动、冲刺冷却变短；被打中后连击清零。
5. **受击**：掉一条命，但**位移不中断、不击飞、不顿帧**，只有 70 帧无敌 + 红晕。
6. **技能**：勇气满按 L，冰封 36 伤；拿到「红之惨剧」后同键变成清屏 + 80 伤 + 长无敌。
7. **BOSS 血条**：只有一根条，打空 → 回满 → 阶段名与技名切换（魔姬 4 次、玛丽苏 5 次）。
8. **视觉对照**：截图和 `art_preview/visual_reference.png` 逐格对比。

## 13. 常见错误（踩了就是“生硬”）

| ❌ 不要 | ✅ 应该 |
| --- | --- |
| 用 `move_and_slide` 处理这套位移 | 手写速度积分（参数在上表） |
| 冲刺瞬间满速 | 3 帧从 45% 推到 100% |
| 敌人受击/玩家受击时顿帧 + 击飞 | 玩家受击不顿帧不击飞；只有命中和技能才顿帧 |
| 子弹自动瞄准敌人 | 只朝鼠标，弱磁吸在 280px 内才有 |
| 落地退出球形态 | 只有松开冲刺才退出 |
| 球形态按一下切换 | 按住冲刺维持 |
| 血条画成 N 根并列 | 一根条，打空回满 |
| 震屏用随机抖动 | 衰减正弦 |
| 用 `_process` 做物理 | `_physics_process` + 60Hz 固定步 |

---

**最后**：网页版的数值都是调过的（每个数字旁边都有注释说明为什么），移植时**先照抄、再调**。
如果 Godot 版和网页版手感不一致，以网页版为准，回头再讨论改数值。
