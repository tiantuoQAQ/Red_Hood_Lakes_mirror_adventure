## 下载与运行

### Windows 可执行版（推荐）

在 **Releases** 页下载 `Red_Hood_Lakes_mirror_adventure.exe`，双击即可运行，无需安装引擎。

- 系统：Windows 10 / 11 64 位
- 显卡：支持 OpenGL 3.3 的任意显卡
- 首次启动稍慢（约 3~5 秒，需要解包资源）

### 网页版

仓库根目录的 `index.html` 即网页版，需要用本地服务器打开：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000/
```

### 源码运行（Godot）

1. 下载 [Godot 4.7.2](https://godotengine.org/download)（标准版，无需 .NET）
2. Import 仓库根目录的 `project.godot`，按 **F5** 运行

## 本次更新内容

### 剧情与流程

- 序章 → 诺登对话 → 操作教程 → 镜中世界 → 猩红魔姬五阶段 → 红之惨剧解锁 → 玛丽苏六阶段 → THANKS FOR PLAYING，**全流程可通关**
- 玛丽苏黑影立绘：自报姓名前名牌显示 **「？？？」**，名字揭晓时弹出称号竖幅
- 对话立绘：说话者不透明、非说话者轻微压暗；对话结束进入走位段立绘立即消失
- 称号竖幅：家徽 + 回纹 + 缎带尾 + 竖排「名字 / 称号」，首次登场弹出
- 梅贝尔对话结束后展示 **THANKS FOR PLAYING** 结局页（不再重跑游戏）

### 战斗系统

- **猩红魔姬 5 阶段**：直线剑气 / 落地突刺 + 追踪剑气 / 追击斩 + 双旋风 / 地刺 + 剑雨 / 锁定突刺锋 + 高频突刺
- **玛丽苏 6 阶段**：符纸环 / 螺旋光轮 + 阴阳球 / 箱庭囚笼（留缺口）/ 镜面反弹符纸 + 预警激光 / 不透明绿幕遮视野 / 镜像翻转（左右颠倒）+ 缩圈弹幕墙
- **新招式**：环形剑阵、三连斩、追踪火球、红色落雷、光轮切割、虚空裂隙、缩圈弹幕
- **攻击全部有预警**：激光 0.7 秒预警线 + 地面光圈，不搞贴脸瞬发
- 战场边界可视化：界外区域被红色火焰烧起，靠近时侧边红光提示；边界随 Boss 移动
- Boss 无瞬移：所有位移改为高速平滑移动

### 玩家操作与数值

| 项 | 数值 |
|---|---|
| 生命 | 5（HUD 为镜子图标，掉血后镜子破碎） |
| 体力 | 120 上限，冲刺消耗 35 |
| 冲刺无敌帧 | 0.2 秒 |
| 移动速度 | 510 px/s |
| 受伤无敌 | 1 秒 |
| MP | 命中 +0.22 / 擦弹 +0.45 |

- **红之惨剧（E）**：清空全屏弹幕 + 对 Boss 大伤害 + 20 秒强化剑气（不再回血）
- **枪火击溃（C）**：鼠标处范围伤害
- **业火（V）**：全屏伤害，无需瞄准
- **L 键**：演示用免费红之惨剧（不消耗 MP、无需解锁）
- **死亡流程**：血光 → 镜裂碎镜 → 停在「按 ENTER 复活」→ **从第一阶段满血重开**，HUD 记录 DEATH 次数

### 表现与音效

- 程序化弹幕：多层辉光 + 白热核心 + 流动条纹 + 粒子/拖尾（玛丽苏为绿色系，魔姬为红色系）
- 激光：柱体脉冲 + 6 道流光 + 移动光团 + 沿线粒子
- 球形态：8 帧拖尾丝带 + 红色激光残影 + 烟雾 + 流光火星
- 地面倒影、Boss 移动粒子、阶段切换白闪、镜碎特效、RETRY 提示
- 音乐：诺登世界 / 镜中世界 / 魔姬 / 玛丽苏 / 过渡段 共 6 首 + 11 个音效

### 界面

- 启动即 1280×720 逻辑分辨率，按 **F11** 全屏 / **F10** 放大，最大化时画面等比放大
- 操作教程（诺登对话后自动弹出）+ 镜子旁告示牌
- 暂停面板：Enter / 鼠标点击继续，R 回标题
