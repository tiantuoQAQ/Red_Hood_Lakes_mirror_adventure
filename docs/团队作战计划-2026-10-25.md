## 2. 协作纪律（避免互相踩）

1. **写文件前先认领**：在 `docs/团队任务板.md` 里把任务标成 `doing(owner)`，不同成员不碰同一文件。
2. **文件分工**（硬边界）：
   - Claude 只碰 `godot/*.gd`、`test/godot_*.gd`
   - DSH 只碰 `art/**`、`src/**`、`tools/**`、`docs/**`、`audio/**`
   - GPT 只产出到 `docs/design/**` 和 `art/ref/**`（新图先放这里，由 DSH 抠图压色后进 `art/`）
3. **每次提交前**：Web 四组测试 + `python tools/check_palette.py art/battle/rek art/char art/portrait` + `git diff --check`。
4. **Godot 回归必须真实渲染**（不加 `--headless`），看日志 marker `0 failure(s)`。
5. **不要 `git reset --hard` / `git clean -fdx`**；逐文件核对、逐文件 add。

## 2.1 新增硬规则：战斗贴图也要过色相检查

`art/battle/**` 原先是检查盲区，实测 **17 张里 11 张越界**（魔姬 10°~30° 橙红、玛丽苏 120°~150° 翠绿）。
已用新工具修正：

```powershell
python tools/hue_lock.py art/battle/**/*.png     # 把色相吸附到 0° / 89.4° / 196.2°，保留亮度与饱和度
python tools/check_palette.py art/battle art/char art/portrait   # 必须 59 张全通过
```

> `tools/force_palette.py` 只适合纯色块小图（对话立绘）；直接用在 2560×1440 的战斗大图上会把整张图去色，**不要再用它处理战斗贴图**。
