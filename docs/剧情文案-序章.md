## 语气规则（从 Black Souls 1 截图提炼）

1. 句子短，一行不超过 30 字；
2. 不写心理，写动作和物件（信、水杯、刀）；
3. 旁白第三人称、独白第一人称，交替；
4. 省略号只用来犹豫，一段最多两次；
5. 最后一句要能当海报。

---

## 序章结构

```
黑场
 └ 旁白：信被找到（2 句）
 └ 信（12 行，逐字打出）
 └ 旁白：信断在这里（2 句）
森林
 └ 旁白：她把信压在桌上，一个人走进森林
 └ 章节卡：悲愤交加的勇者 / 踏上了寻回珍视之人的旅途
 └ 旁白：然后，她没能走出那片森林        ← 反转，接醒来
黑场 → 醒来（诺登）
```

## 信（完整）

```
格林：
我要走了。
这一次，我不知道自己还能不能回来。
我知道，这只是我的任性。
请你原谅我。
我不想把你卷进这件事里来。
你总说，让我等你。
可这一次，我不能再等了。
我不会让这个世界如她所愿。
只要我还没有死，这个故事就永远不会结束。
所以，别难过。
等我回来——我们还有很多话，没来得及说完。
```
