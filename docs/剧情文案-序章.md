# 序章文案 · 草案 v1（待讨论）

> 参考：Black Souls 1 小红帽线结尾的语气——短句、省略号多、第一人称独白、宿命感，
> 不解释、不煽情，把情绪压在物件和动作里。
> 下面的「指令」可以直接粘进 `src/story.js` 覆盖 `prologue`。

## 提炼出来的语气规则

1. **句子短**。一行不超过 30 字，两句一组，中间敢留空。
2. **不写心理，写动作和物件**。血、刀、篮子、信，比「我很悲伤」有力。
3. **旁白第三人称，独白第一人称**，两者交替，形成「镜头拉远再拉近」。
4. **省略号用于犹豫，不用于拖沓**。一段里最多两次。
5. **最后一句要能当海报**（「只要我还没有死，这个故事就永远不会结束」这种）。

## 待确认（问过再定稿）

1. **「珍视之人」是谁？** BS1 线结尾里蕾克失去的、要追回来的那个人——是诺登？是村子的人？这决定独白的指代。
2. **要不要「信」这个物件？** 参考截图里有一句「桌子上留着一封信」。开场用信做钩子，还是留到结局回收？
3. **蕾克的动机偏哪边？** 复仇（要杀了玛丽苏）／救人（把人带回来）／阻止世界（不让它如她所愿）——三种语气不同。
4. **尺度到哪？** BS1 原作文本偏重、偏血腥。这是社团比赛的展示场合，评委会在场：保持「有血」但收着写，还是原汁原味？
5. **独白和旁白的比例？** 草案是 3 句旁白 + 3 句独白，要不要再压成各 2 句（更冷）。
