# 项目上下文（供圆桌评审）

《镜》(MIRROR)：CODEJAM 2026 参赛作品。横版 2D 弹幕躲避 + 射击（bullet-hell × 平台动作）。
网页版 = HTML5 Canvas + 原生 JS，零依赖零构建，固定 1/60 步长，逻辑分辨率 1280×720，地面线 y=574，世界宽 2400。
现在要把它移植成 **Godot 4**，交接文档已写好（见下），但移植方已经开始跑偏/卡住。

## 核心机制摘要

- 输入：A/D 或 ←/→ 移动；Space 跳；Shift/K/**鼠标右键** 冲刺；J/Z/**鼠标左键** 射击；L/X 技能。
- 射击：朝**鼠标世界坐标**，无自动瞄准；鼠标从未移动过才退化为面朝方向；子弹距 BOSS 280px 内弱磁吸。
- 冲刺：速度 1020，持续 12 帧，无敌 16 帧，冷却 16 帧（结束后起算），起步 3 帧从 45%→100%，结束滑行 6 帧（0.72 保留率），8 帧输入缓冲。
- **球形态**（核心）：在空中 + 按住 W + 按下冲刺 + 体力>20 → 变无敌光球；进入瞬间 vx*=0.4、vy=-450，前 5 帧强制上冲；期间方向键直给速度（合速度 450）、体力 -32/s；落地不退出（贴地悬浮）；**松开冲刺立刻变回人**；体力耗尽退出；地面上按 W+冲刺只算普通冲刺。
- 伤害/无敌：3 条命；受击不击飞不顿帧，70 帧无敌；命中与技能才顿帧（4~10 帧），震屏用衰减正弦。
- 擦弹：判定半径 4、擦弹环 30；连击窗口 80 帧；每 5 连 +0.5 倍勇气，上限 3 倍；每次擦弹返还冲刺冷却 2 帧。
- 技能：勇气满 100；冰封 36 伤/130 帧无敌；解锁「红之惨剧」后同键升格为清屏 + 80 伤 + 200 帧无敌。
- BOSS 血条：**整场只有一根条**，打空 → 下一阶段 → 血条自动回满（魔姬回满 4 次共 5 段，玛丽苏回满 5 次共 6 段），界面显示 STAGE n/N 或 STAGE n/?。
- 弹幕 10 种：ring / mirrorFan / spiral / rain / lances / orbit / crossfire / laser / bossDash / homing。
- 剧情：11 章、183 句台词、19 种演出命令（数据驱动，已导成 JSON）。

## 球形态特效（6 层，纯图元绘制）

呼吸缩放 → 径向渐变光晕（中心纯白、30% 红、58% 红 20%）→ 3 段青色旋转弧 → 白色内核 → 每 26 帧一圈外扩冲击波 → 每 2 帧反向撒粒子拖尾；全部用 `lighter` 叠加混合。

## 移植方（GPT）已经出现过的问题

1. 不知道「空中按 W + 冲刺变球」这个机制（第一版交接没写清）。
2. 不知道射击要跟随鼠标（做成了自动瞄准/固定朝向）。
3. 不知道玩家战斗贴图在哪（其实是程序化占位，`art/rek/` 为空）。
4. 手感生硬（疑似用了 move_and_slide、冲刺瞬间满速、受击顿帧/击飞）。
5. 界面做得很丑（没有对照网页版截图，血条做成了分段并列条）。
