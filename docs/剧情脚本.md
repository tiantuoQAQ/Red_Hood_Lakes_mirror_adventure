# 剧情脚本与演出系统

> 代码已经接好了，**改文案不用碰逻辑**：只需要改 `src/story.js` 里的数据。
> 演出有三种形式（对应制作人给的三张参考图），另有通用底部对话框。

---

## 1. 三种演出形式

| 形式 | 指令 | 长什么样 | 用在哪 |
| --- | --- | --- | --- |
| 章节卡 | `card` | 背景 + 居中大立绘 + 底部两行大字幕 | 开场、章节标题、结局 |
| 场景气泡 | `bubble` | 小人站在场景里，头顶带名字的对话框 | 场内吐槽、短对话 |
| 双立绘对峙 | `duel` | 左右两张立绘 + 中间偏下的对话条 | 对峙、重要转折 |

另有一个 `say`（通用底部对话框），用在对白较长、不想压画面的时候。

预览图：`art_preview/story_forms.png`（`_verify_story.html` 可复现）。

## 2. 指令表

```js
{ t:'scene',  bg:'night'|'forest'|'mirror' }    // 切背景（只换底色，不换地图）
{ t:'fade',   to:'black'|'clear', frames:45 }   // 黑场过渡
{ t:'wait',   frames:30 }                       // 空等
{ t:'card',   line1:'主标题', line2:'副标题', frames:170 }
{ t:'bubble', who:'蕾克', text:'……' }
{ t:'duel',   left:'蕾克', right:'玛丽苏', text:'……', hint:'按 Enter 继续' }
{ t:'say',    who:'诺登', text:'……' }           // who 留空 = 旁白
{ t:'battle', boss:'crimson', after:'crimson_fall' }
{ t:'grant',  skill:'red_tragedy', banner:'红之惨剧' }
{ t:'next',   chapter:'wake' }
{ t:'end',    kind:'win' }
```

角色 id（写进 `who` / `left` / `right`）：

| id | 名字 | 占位色 |
| --- | --- | --- |
| `rek` | 蕾克 | 红 |
| `rek_crimson` | 猩红魔姬 | 暗红 |
| `norden` | 诺登 | 亮红 |
| `marysue` | 玛丽苏 | 青蓝 |
| `mabel` | 梅贝尔 | 灰 |

## 4. 怎么加/改台词

1. 打开 `src/story.js`，找到对应章节；
2. 在 `cmds` 数组里加一行，例如：

```js
{ t: 'say', who: '诺登', text: '你以为我会拦你吗？' },
```

3. 存盘刷新页面即可，**不用改代码，也不用重启**。

> 目前所有台词都是 `【待填】` 占位。改的时候直接替换文字，别动 `t` / `who` 字段。

## 5. 立绘去哪里

代码会自动找这几个路径，**放进去就生效，没有就画色块占位**：

| 角色 | 路径 |
| --- | --- |
| 蕾克 | `art/portrait/rek.png` |
| 猩红魔姬 | `art/portrait/crimson.png` |
| 诺登 | `art/portrait/norden.png` |
| 玛丽苏 | `art/portrait/marysue.png` |
| 梅贝尔 | `art/portrait/mabel.png` |

要求：竖构图、透明背景（白底也行，先占位）、人物朝画面右（右侧角色会自动镜像）、建议 512×768 或更高。

## 6. 操作

| 键 | 作用 |
| --- | --- |
| `Enter` / `空格` / 鼠标左键 | 继续（文字没打完则先补完当前句） |
| `Tab` | 跳过整段演出，直接开打本关 |

### 手感细节（都是刻意做的，别当成 bug）

- **打字机带标点停顿**：句号/问号停 14 帧，逗号停 7 帧，读起来才有呼吸；
- **按一下就补完当前句**，再按才翻页——不会出现「按了没反应」；
- **防连点**：两次推进至少隔 4 帧，手滑不会一次跳两页；
- **转场不需要按键**：黑场、切场景播完自动往下走；
- 对话框浮起、立绘滑入、气泡弹入都带缓动，不是硬切；
- 立绘有 2px 的极轻呼吸浮动，画面不死。

## 6.1 想改演出节奏，只动这几个数

都在 `src/cutscene.js` 顶部：

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `CPS` | 0.9 | 每帧打几个字（60 帧 ≈ 54 字/秒） |
| `PAUSE` | 见代码 | 各标点的停顿帧数 |
| `BOX_IN` | 9 | 对话框浮起帧数 |
| `PORTRAIT_IN` | 14 | 立绘滑入帧数 |
| `CARD_LINE1_IN` / `CARD_LINE2_IN` | 18 / 16 | 章节卡两行字幕的淡入帧数 |

## 7. 调试参数

| URL 参数 | 作用 |
| --- | --- |
| 无 | 默认从序章开始播 |
