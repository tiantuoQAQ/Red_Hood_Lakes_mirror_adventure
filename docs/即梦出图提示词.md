# 即梦出图提示词 · 《镜》角色贴图

> 用途：把角色设定图交给即梦，生成可用的游戏贴图。
> 即梦**不能联网**，所以本文件里不出现任何作品名、角色名让它联想——全部改用外观看图说话。
> 参考图（图 14–16）只当**构图、角色大小、姿态、画面比例**的参考，**不要复制里面的角色形象**。

## 1. 通用规则（每个角色都要复制这一段）

把下面三段一起喂给即梦，一次一个角色。

### 1.1 正向提示词（每个角色开头都加这段）

```
游戏角色立绘贴图，单个角色，侧视角，完整全身，面朝画面右侧，站在画面底部中央。
日式赛璐璐平涂风格，干净的黑色线稿，硬边阴影，不写实、不厚涂、不油画。
纯白背景，角色四周留出空白，不要任何地面、阴影、文字、边框、水印。
配色严格限制为三种颜色加黑白灰：纯红 #FF0000、黄绿 #82FF00、青蓝 #00BAFF，
其余部分只能用纯黑、纯白、中性灰（灰的 RGB 三个数值必须相等）。
画面里不允许出现第四种颜色。
角色高度约占画面高度的 80%。
```

### 1.2 反向提示词（一定要填）

```
第四个颜色，橙色，黄色，紫色，粉色，棕色，肤色，金色，藏青，彩色描边，
彩虹，彩色光晕，彩色阴影，环境反光，写实照片，3D 渲染，厚涂，油画，
多个角色，正面角度，背面角度，侧脸特写，文字，水印，logo，边框，
地面，投影，复杂背景，星星特效，粒子特效，多手多脚，畸形手指
```

### 1.3 生成参数建议

| 项目 | 建议 |
| --- | --- |
| 比例 | 竖构图（3:4 或 9:16），给全身留高度 |
| 参考图强度 | 造型参考调到中等偏低（**太高会照抄原图的颜色**） |
| 生成张数 | 一次 4 张，挑最符合的一张 |

## 2. 每个角色的提示词（直接复制）

> 用法：先上传这个角色的设定图（1–2 张）+ 一张图 14–16 里的截图（只用来对齐角色大小与姿态）。
> 然后粘贴：`1.1 正向` + 下面**该角色那一段** + `1.2 反向`。

### 2.1 小红帽 蕾克（主角，红）

```
角色是一个少女冒险者，戴着带兜帽的斗篷，兜帽顶部有两个尖尖的兽耳，
斗篷下摆是锯齿状剪裁，脖子上系着黑色蝴蝶结，露出双腿，赤脚，短发。
全身主色为纯红 #FF0000，斗篷是亮红，衣服内侧用暗红，眼睛和蝴蝶结用纯黑，

表情平静，双手自然下垂，站姿。
```

## 3. 动作与动画（第二阶段再做）

**先只要静态待机**。原因：即梦无法保证多帧一致性，一次要 4 帧，出来的手脚位置会各不相同，反而不能用。
游戏里的呼吸、上下浮动、挤压拉伸都是**代码做的**，一张静态图就够。

等 9 张静态图都验收通过、风格统一了，再补下面这些：

| 动作 | 谁需要 | 提示词追加内容 |
| --- | --- | --- |
| 待机动画 | 全部 | （静态图 + 代码浮动即可，不需要即梦） |
| **冲刺拖尾** | **只要小红帽** | `同一个角色做向前冲刺的姿势，身体前倾 20 度，一只手臂向前伸出，身后拖出 3 层逐渐变淡的纯白残影，残影不改变颜色，只有透明度递减` |
| 跳跃 | 小红帽 | `同一个角色做向上跳起的姿势，双腿收起，双臂上举` |
| 受击 | 小红帽 | `同一个角色向后仰，一只手抬起护住面前` |

> 冲刺拖尾如果要 3 帧，就分 3 次生成：第 1 次 3 层残影，第 2 次 2 层，第 3 次 1 层。
> **不要让它一次画一张"3 帧拼在一起"的图**——它会画成三个不同的人。

## 4. 验收清单（每张图都要过）

- [ ] 只有一角色，全身完整，没有切边
- [ ] 面朝右，侧视
- [ ] 纯白背景，没有地面阴影、文字、边框
- [ ] 画面里只有三种颜色 + 黑白灰，**没有肤色、没有棕色、没有金黄**
- [ ] 灰色部分是真正的灰（不是偏蓝的深灰、不是偏暖的米灰）
- [ ] 剪影能一眼认出来是谁（把它涂成全黑也能分辨）
- [ ] 同一色系里不同角色的**明度**有明显差别
- [ ] 没有多手多脚、没有畸形手指

## 5. 即梦常见失败，与补救办法

| 症状 | 原因 | 补救 |
| --- | --- | --- |
| 皮肤画成肉色/橙色 | 模型默认画人 | 反向提示词里保留"肤色"，正向里明确指出"皮肤用接近白的浅灰" |
| 出现第四种颜色（紫、橙、粉） | 渐变或光晕 | 正向强调"硬边阴影，不用渐变"，反向加"彩色光晕、彩色阴影" |
| 背景变复杂 | 默认加场景 | 正向第一句就写"纯白背景"，反向写"复杂背景" |
| 画成正面 | 参考图是正面设定 | 正向写"侧视角、面朝右"，参考图里优先用侧面那张 |
| 全身被裁掉 | 比例不对 | 改竖构图 9:16，并写"角色高度约占画面高度 80%" |
| 画成三个小人并排 | 参考图是三视图 | 正向写"单个角色"，反向写"多个角色、并排" |
| 颜色对了但剪影变了 | 参考强度太低 | 把造型参考强度调高，但**同时**在正向重申颜色，防止照抄原图配色 |
