## 1. 通用规则（每个角色都复制这三段）

### 1.1 正向提示词（放在最前面）

```
游戏角色立绘贴图，单个角色，侧视角，完整全身，面朝画面右侧，站在画面底部中央。
日式赛璐璐平涂风格，干净黑色线稿，硬边阴影，不写实、不厚涂、不油画。
纯白背景，角色四周留白，不要地面、阴影、文字、边框、水印。
配色严格限制为三种颜色加黑白灰：纯红 #FF0000、黄绿 #82FF00、青蓝 #00BAFF，
其余只能用纯黑、纯白、中性灰（灰的 RGB 三个数值必须相等）。
画面里不允许出现第四种颜色。
角色高度约占画面高度的 80%。
```

### 1.2 反向提示词（必填）

```
第四个颜色，橙色，黄色，紫色，粉色，棕色，肤色，金色，银色，绿色，藏青，彩色描边，
彩虹，彩色光晕，彩色阴影，环境反光，写实照片，3D 渲染，厚涂，油画，
多个角色，并排角色，正面角度，背面角度，文字，水印，logo，边框，
地面，投影，复杂背景，星星特效，粒子特效，多手多脚，畸形手指
```

### 1.3 参数

| 项目 | 建议 |
| --- | --- |
| 比例 | 竖构图 3:4 或 9:16 |
| 参考图 | 该角色的**设定图 1 张** + 图 14 或 16（只对齐大小与构图） |
| 参考强度 | 中等偏低。太高会**照抄原图的蓝发/绿翅膀/粉发**，正好违反配色规则 |
| 数量 | 一次 4 张，挑 1 张 |

## 3. 动作清单（每个动作一张图，全部侧身朝右）

即梦**不能一次画好几帧还保持一致**。所以每个动作单独生成一张，动作差异靠提示词说清楚。

### 3.1 蕾克需要 7 张

| 编号 | 文件名 | 动作 | 追加到 2.1 后面的描述 |
| --- | --- | --- | --- |
| 1 | `rek_idle_a.png` | 待机 A | `站姿，重心在后脚，双手自然下垂，肩线放松，微微侧头看向画面右侧` |
| 2 | `rek_idle_b.png` | 待机 B | `与待机 A 完全相同的姿势与构图，只有躯干略微下沉、肩线下压，其他部位一个像素都不要变` |
| 3 | `rek_dash.png` | 冲刺 | `身体前倾约 20 度，一只手臂向前伸出，另一只手臂向后，后脚蹬地，衣摆与头发向后飘` |
| 4 | `rek_jump.png` | 起跳 | `双腿收起贴近身体，双臂向上，身体向上延伸` |
| 5 | `rek_fall.png` | 下落 | `双腿自然张开，手臂略微张开，衣摆向上翻` |
| 6 | `rek_hurt.png` | 受击 | `上半身向后仰，一只手抬起护在面前，表情痛苦但不变形` |
| 7 | `rek_ball.png` | 光球形态 | 见 3.3，单独一段 |

### 3.2 待机动画怎么做

**推荐：只出 `rek_idle_a` 一张，动画由代码完成。**

代码会做上下浮动 2px、整体缩放的呼吸感、极轻微左右摇摆。在 40px 的游戏尺寸下完全够用，
而且永远不会出现"两帧对不齐"的问题。

如果坚持要 2 帧手绘循环，就额外生成 `rek_idle_b`，提示词必须强调"与 A 完全相同的姿势与构图"。
**但要有心理准备：即梦基本做不到"只改一处、其他像素不动"，两帧叠起来会抖**，那种抖比代码浮动更难看。

### 3.3 光球形态（`rek_ball.png`）

```
一个正圆形的发光球体，直径约占画面高度的 70%，位于正中央。
从中心到边缘做径向渐变：正中心是纯白，向外逐渐变成纯红 #FF0000，
球体表面有几道白色的同心细环与裂纹，像玻璃球。
球体外圈有一圈 1.5 像素宽的纯白描边。
纯白背景，不要其他任何元素。
```

> 光球不需要侧面——它是圆的，任何角度都一样。

### 3.4 冲刺拖尾（`rek_trail.png`）

**建议仍然用代码画**：现有代码会跟随角色真实位置生成残影，比贴图更贴合动作。

如果一定要贴图，让即梦出 1 张「冲刺姿态的纯白剪影」：

```
同一个角色冲刺姿态的纯白剪影，只有形状，没有颜色和细节，纯白填充，
除纯白背景外不要任何其他元素，单独一张。
```

代码会把它按 3 层叠在身后，透明度递减。

## 4. 验收清单（每张都要过）

- [ ] 只有一个角色，全身完整，没被裁切
- [ ] 面朝右，侧视
- [ ] 纯白背景，无地面阴影、无文字、无边框
- [ ] 只有三种颜色 + 黑白灰：**没有肤色、没有金色、没有银色、没有紫粉蓝绿**
- [ ] 灰色是真正的灰（R=G=B），不是偏蓝的深灰、不是偏暖的米灰
- [ ] 涂成全黑的剪影能认出是谁
- [ ] 同色系里不同角色的明度差别明显
- [ ] 没有多手多脚、没有畸形手指

## 5. 即梦常见失败与补救

| 症状 | 原因 | 补救 |
| --- | --- | --- |
| 皮肤画成肉色 | 模型默认画人 | 正向写死"皮肤用接近白的浅灰"，反向保留"肤色" |
| 出现紫/粉/橙 | 渐变或彩色光晕 | 正向写"硬边阴影、不用渐变"，反向加"彩色光晕、彩色阴影" |
| 蓝发/绿翅膀被照抄 | 参考强度太高 | 降低参考强度，并在正向开头就声明只用三色 |
| 画成正面 | 参考图是正面设定 | 正向写"侧视角、面朝右"，优先喂侧面那张 |
| 全身被裁 | 比例不对 | 改 9:16 竖构图，写"角色高度占画面 80%" |
| 画成三小人并排 | 喂了三视图 | 正向写"单个角色"，反向写"多个角色、并排角色" |
| 剪影变了 | 参考强度太低 | 调高参考强度，同时正向重申颜色，防止连带照抄原配色 |
