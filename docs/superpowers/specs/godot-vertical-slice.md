# Godot 垂直切片规格

## 目标

把现有 HTML 原型迁入 Godot 4.7.2，先交付一个可直接运行的横版 Boss Rush 战斗切片：标题界面、蕾克移动/跳跃/冲刺、猩红魔姬战、魔姬胜利后进入玛丽苏战斗预览。

## 约束

- Godot 4.7.2，Compatibility 渲染器，GDScript。
- 逻辑分辨率 1280x720，窗口可缩放。
- 色彩遵守项目三色规则：红 `#FF0000`、黄绿 `#82FF00`、青蓝 `#00BAFF`，其余使用中性灰。
- 对话立绘、地图待机立绘、战斗小人分开使用。
- 魔姬待机动作固定使用动作 02；攻击顺序为 01 俯冲、04 突刺、03 挥刀、02 回待机。
- 法环、粒子、冲刺拖尾作为独立程序化特效层，不把 GIF/MP4 直接当游戏逻辑源。

## 交互

- `A/D` 或方向键移动。
- `Space` 跳跃。
- `Shift/K` 冲刺，冲刺期间无敌并生成红色残影拖尾。
- `J/Z` 发射红色玩家弹丸。
- `Esc` 返回标题。

## 验收

启动后能看到标题并按键进入战斗；玩家可以移动、跳跃和冲刺；冲刺拖尾平滑衰减；魔姬有悬浮、红色法环、粒子和四段攻击关键帧；击败魔姬后可以切换到玛丽苏战斗预览；窗口缩放不改变逻辑比例。
