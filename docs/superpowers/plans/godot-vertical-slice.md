# Godot 垂直切片实施计划

1. 创建 `project.godot`、主场景和单一入口脚本，锁定 1280x720 与 Compatibility 渲染器。
2. 在入口脚本中实现标题、战斗、胜利和 Boss 切换状态机，以及键盘输入。
3. 实现玩家移动、跳跃、冲刺无敌帧、红色残影/拖带/火星特效和玩家射击。
4. 实现魔姬 Boss 的阶段血条、红色法环、粒子、四段动作关键帧和四种刀刃弹幕。
5. 接入玛丽苏三张关键帧与绿色法环/粒子，作为第二战可玩的初版。
6. 复制已验收的战斗关键帧到正式仓库的 `art/battle/`，不覆盖现有立绘和对话资产。
7. 用 Godot headless 检查项目可导入，并运行现有 Node/Python 回归测试及色板检查。
